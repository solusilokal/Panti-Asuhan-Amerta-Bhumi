# Mini Website Panti Asuhan Amerta Bhumi

Proyek ini telah dikonfigurasi menggunakan **React 18**, **Vite**, **Tailwind CSS**, dan **Lucide Icons** agar dapat langsung di-preview di browser.

---

## 🚀 Cara Menjalankan & Preview

Ada beberapa cara mudah untuk menjalankan preview website ini:

### Cara 1: Menggunakan File Batch (Paling Mudah di Windows)
Cukup **klik dua kali** salah satu file berikut di File Explorer:
- **`jalankan-dev.bat`** : Menjalankan development server dan otomatis membuka browser di `http://localhost:5173/`.
- **`jalankan-preview.bat`** : Menjalankan preview hasil production build.

---

### Cara 2: Melalui Terminal / Command Prompt (CMD)

Buka folder ini di Terminal / CMD, lalu jalankan:

```bash
npm run dev
```

Jika menggunakan **PowerShell** dan muncul pesan *Execution Policy*:
```powershell
npm.cmd run dev
# atau
cmd /c npm run dev
```

Buka URL yang ditampilkan di terminal (biasanya **http://localhost:5173/**).

---

### Perintah Lainnya

| Perintah | Keterangan |
|---|---|
| `npm run dev` | Menjalankan server lokal (Hot Reload) |
| `npm run build` | Membuat build production di folder `dist/` |
| `npm run preview` | Menjalankan server preview dari build production |
